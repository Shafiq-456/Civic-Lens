## Key UI decisions
- One big map card that switches India ↔ Tamil Nadu modes (rather than two maps) keeps the flagship layout exactly on the lg:grid-cols-5 (3+2) spec and avoids duplicate India renders; "Open Tamil Nadu detail" is only offered for `isFocusState`.
- District↔polygon joining relies on `geoName` (DB stores geojson spellings like 'Thiruvallur'); AC/PC metadata shown straight from raw feature properties via a normalised name→props Map, since GeoMap's `onSelect` only passes the name.
- Layer switcher uses real ARIA radiogroup semantics; every clickable card/polygon has keyboard equivalents.
- Teal primary (`bg-teal-700`) + amber accents only; no indigo/blue anywhere.
